# אפליקציית ניהול אירועים ומלצרים

אפליקציית ווב (PWA) בעברית לניהול עסק של אספקת מלצרים וניהול אירועים.
כל הנתונים נשמרים **מקומית במכשיר** — אין שרת, אין חשבון, ולא נדרש אינטרנט אחרי ההתקנה.

## מה יש באפליקציה

- **עבודה חדשה** — טופס מלא: שם לקוח, תאריך, שבת/יום חול, סוג אירוע, כמות אורחים,
  שעות, מנהל, כמות מלצרים (עם תיבת שם לכל מלצר), תשלום למלצר, מלצר מיוחד,
  סכום מהלקוח + סימון "שולם", מיקום, סוג מקום, סוג צלחות, והערות.
  יש גם חישוב אוטומטי של עלות המלצרים והרווח המשוער.
- **רשימת העבודות** — כל האירועים בתצוגה מכווצת (שם, תאריך, מיקום). לחיצה פותחת את כל הפרטים.
  חיפוש ומיון (חדש→ישן / ישן→חדש / הקרובים).
- **לוח שנה** — חודשי, בעברית. ימים עם אירועים מודגשים. לחיצה על יום מציגה את האירועים שבו,
  ולחיצה על אירוע מקפיצה לרשימה עם כל הפרטים.
- **גיבוי ושחזור** — כפתור "גיבוי" בראש המסך שומר קובץ של כל הנתונים, וניתן לשחזר ממנו.

## איך מתקינים על הטלפון (אנדרואיד)

1. פותחים את כתובת ה-Pages של הפרויקט בדפדפן Chrome בטלפון.
2. תפריט (⋮) → **הוספה למסך הבית** (Add to Home screen).
3. מופיע אייקון של האפליקציה — פותחים אותה כמו כל אפליקציה רגילה.

> חשוב: הנתונים נשמרים במכשיר הספציפי. כדאי מדי פעם ללחוץ **גיבוי → שמור גיבוי**
> ולשמור את הקובץ (למשל ב-Google Drive) כדי לא לאבד מידע.

## קבצים

- `index.html` — מבנה המסכים
- `styles.css` — עיצוב (RTL, מותאם לנייד)
- `app.js` — כל הלוגיקה
- `sw.js` + `manifest.webmanifest` — הפיכה לאפליקציה שמותקנת ועובדת offline
- `icons/` — אייקונים

האייקונים נוצרים ע"י `scripts/make-icons.js` (הרצה: `node scripts/make-icons.js`).
